# Project Skills

This folder contains project-local Codex skill drafts for 0xDriver/OODrive.
They are not automatically installed into the global Codex skill directory.

## Available Drafts

- `oodrive-scenario-operator`: guides Codex through the OODrive scenario
  generation, queue, run, evaluate, replay, and export CLI loop.
- `waymo-multiview-fail2drive-reconstruction`: guides Codex through
  direction-aware Waymo multiview object transcription, Fail2Drive XML
  placement, render evidence, and visual QA.
